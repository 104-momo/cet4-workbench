# 四级冲刺工作台（CET4 Workbench）

面向高考英语 70 分水平考生、备考 2026 年 12 月英语四级（CET-4）的每日学习工作台。

## 功能
- **今日任务**：按阶段（基础→能力→真题→冲刺）自动生成每日学习清单，可勾选打卡（数据保存在本机浏览器 localStorage）
- **备考计划**：15 周 4 阶段完整计划 + 分值/通过线说明
- **学习资源**：词汇、听力、真题、写作翻译、官方入口等可直达链接
- **打卡日历**：月份视图打卡记录

## 使用
直接打开 https://104-momo.github.io/cet4-workbench/ 即可使用。
也可以下载 `index.html` 在本地浏览器打开（本地打开打卡数据同样有效）。

> 打卡数据保存在本机浏览器 localStorage，换设备或清缓存会清空。
